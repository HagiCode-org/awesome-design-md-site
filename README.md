# awesome-design-md-site

[![last commit](https://img.shields.io/github/last-commit/HagiCode-org/awesome-design-md-site)](https://github.com/HagiCode-org/awesome-design-md-site/commits/main)

**快速找到、对比并借鉴设计系统。** `awesome-design-md-site` 是一个静态画廊站点，收录上游 [awesome-design-md](https://github.com/VoltAgent/awesome-design-md) 仓库中的设计系统条目，让你不必逐个翻仓库，就能在浏览器里搜索、预览并拿走想要的 `DESIGN.md`。

**在线访问：[https://design.hagicode.com](https://design.hagicode.com)**

适合想研究或复用某套设计系统的设计师、前端开发者，以及借助 AI 搭建界面的开发者。

## 你可以做什么

- **实时搜索**：在首页搜索框输入关键词，标题、摘要以及 README 与 DESIGN 正文都会参与匹配，结果即时更新。
- **浏览画廊**：每个设计系统在首页都有一张带预览图的卡片，点击即可进入详情页。
- **README 与 DESIGN 切换**：详情页中可在条目的 README 与 DESIGN 文档之间切换阅读。
- **预览主题与宽度**：预览图提供浅色与深色两套，并可在 Fit、Tablet、Mobile 三种宽度之间切换。
- **打开原始预览**：需要查看原始页面时，可以在新标签页打开该条目的原始预览。
- **下载 DESIGN 文件**：一键下载 `DESIGN.md`，放进自己的项目，让 AI 助手按这套风格生成界面。
- **十种界面语言**：界面支持 en-US、zh-CN、zh-Hant、ja-JP、ko-KR、de-DE、fr-FR、es-ES、pt-BR、ru-RU。

## 使用方式

1. 打开 [https://design.hagicode.com](https://design.hagicode.com)。
2. 在搜索框输入关键词，或直接浏览首页卡片，找到感兴趣的设计系统。
3. 点击卡片进入详情页，在 README 与 DESIGN 之间切换阅读。
4. 切换预览的浅色 / 深色主题，以及 Fit / Tablet / Mobile 宽度，对比不同场景下的效果。
5. 需要原始页面时在新标签页打开预览；需要复用时下载 `DESIGN.md`。
